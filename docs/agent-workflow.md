# AI resume workflow

## 1. Collect evidence privately

Start with the candidate's current resume and any work samples or corrections they provide. Keep source files and personal details in a private workspace. Record factual claims and their evidence there; do not copy real candidate information into this public example repository.

## 2. Build a grounded baseline

Draft a concise summary, experience, skills, projects, and education from confirmed evidence. Preserve official titles, dates, employer/client relationships, and project context. Flag uncertain details for the candidate rather than filling gaps by inference.

## 3. Tailor to a role

Compare the supplied job description to the baseline. Reorder and rephrase supported experience to foreground relevant work. Mark each important requirement as supported, requires confirmation, or unsupported. Omit unsupported claims and ask about material gaps.

## 4. Review the output

Check the source for accuracy, spelling, readable structure, and working links. Compile the LaTeX twice, inspect extracted text and the rendered page, and check PDF metadata. Have the candidate review the final version.

## 5. Keep public and private material separate

Store application-specific source, job descriptions, and PDFs in private storage. Before publishing workflow changes, inspect the staged file list and scan all staged text and metadata. The public sample must remain fictional; do not commit real resumes or generated candidate PDFs.
