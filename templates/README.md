# Resume template

`resume_template.tex` is a reusable, single-column LaTeX starter. Copy it into a private workspace, replace every bracketed field, and verify that displayed contact details match the hyperlink targets. Add or remove role and skill rows as needed.

Keep claims grounded in candidate-confirmed evidence. Compile twice with pdfLaTeX, inspect extracted text and the rendered page, and review the final PDF with the candidate. Do not commit personal resumes, job descriptions, or generated PDFs to this public repository.
